# EH-08-05 health/statistics performance benchmark

The versioned runner is `pnpm benchmark:reads`. It executes PostgreSQL-backed
application services against a selected archive and writes non-personal JSON
evidence to `docs/benchmarks/eh-08-05-latest.json` (override with `--output`).
The report includes the existing bounded read/search cases and these
health/statistics cases:

- archive health overview;
- all-time archive statistics;
- archive statistics over a bounded UTC date window.

Each case records cold-session and warm-session latency distributions. The
runner captures `EXPLAIN (ANALYZE, BUFFERS, COSTS OFF, FORMAT JSON)` summaries
for the health aggregates and statistics totals, direction, activity, and
conversation queries. It also records the database/server version, Node and
Prisma versions, CPU/RAM/storage, container limits, corpus counts and checksum,
archive-selection rule, cache conditions, and statistics publication boundary.

The acceptance target is warm p95 <= 2,000 ms for every representative case at
the requested corpus scale. No index, cache, or incremental-maintenance change
may be made without a measured before/after comparison and reconciliation
tests. Statistics always derive from messages linked to both a completed
snapshot and a completed import job; the benchmark does not introduce a
second data store or a cache invalidation path.
