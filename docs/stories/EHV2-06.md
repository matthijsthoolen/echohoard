# EHV2-06 stories — Owner-controlled voice and video-note transcription

Owning feature: `docs/tasks/EHV2-06.md`. Transcription goes through LiteLLM using the owner-selected model; transcript content is private hostile data.

## EHV2-06-01 — Add transcript, run, and manual-authority persistence

- **Goal:** Persist model-generated transcript versions and human corrections without conflating them with message text.
- **Repository:** `/home/matthijs/projects/echohoard`
- **Context / constraints:** Each transcript links to an attachment/media digest and job/run. A human edit becomes authoritative and automatic runs cannot overwrite it.
- **Work to do:** Add domain/schema/migration and ports for transcription request/run/version, language, selected model, timestamps, status/error class, source media hash, active text, human editor marker, and immutable version history.
- **Acceptance criteria:** One attachment can have multiple runs/versions and one active transcript; manual edit creates a version and locks automatic replacement; changed media digest invalidates applicability without deleting history; cross-archive links fail.
- **Verification:** Domain tests and PostgreSQL migration/constraint/version-authority tests.
- **Out of scope:** LiteLLM calls, settings UI, queueing, transcript rendering, or purge.
- **Blocked by:** EH-13-08.
- **Priority:** High.
- **Model class:** Medium.

## EHV2-06-02 — Select an allowed LiteLLM transcription model in settings

- **Goal:** Let the owner choose the model used for future transcription jobs from the existing LiteLLM catalog.
- **Repository:** `/home/matthijs/projects/echohoard`
- **Context / constraints:** Discover only models explicitly allowed for EchoHoard/audio transcription; do not accept arbitrary provider/model URLs or credentials. Settings store a model identifier, not a secret.
- **Work to do:** Add model-catalog port, cached bounded discovery, archive transcription setting, admin UI selector, unavailable-model behavior, and safe default/unset state.
- **Acceptance criteria:** Only allowlisted transcription-capable models appear; selection persists and is stamped onto new runs; removal/unavailability does not rewrite old runs and blocks new work clearly; no provider credentials reach browser/database/logs.
- **Verification:** Unit catalog/settings tests and browser flows for select/change/unavailable/empty/error states.
- **Out of scope:** Transcription execution, LiteLLM deployment, pricing UI, or per-file override.
- **Blocked by:** EHV2-06-01.
- **Priority:** High.
- **Model class:** Medium.

## EHV2-06-03 — Implement the bounded LiteLLM transcription adapter

- **Goal:** Send an eligible media derivative to the selected model and return a sanitized transcript result.
- **Repository:** `/home/matthijs/projects/echohoard`
- **Context / constraints:** Use secret-file credentials and the existing private LiteLLM endpoint. Enforce supported audio extraction, size/duration/time limits, model allowlist, no arbitrary URL, no content logging, and clear retry categories.
- **Work to do:** Add media-to-audio preparation behind a bounded subprocess port where needed; implement LiteLLM audio transcription request/response adapter; validate text/language/timing metadata and redact errors.
- **Acceptance criteria:** Only owner-selected allowed model and CAS attachment bytes are used; credentials/media/transcript never appear in argv/logs; timeout/limit/provider failures are classified; temporary derivatives clean after success/failure.
- **Verification:** Adapter contract tests with fake HTTP/subprocess, sentinel scans, timeout/oversize/format/cleanup cases, and one private synthetic endpoint probe kept outside public evidence.
- **Out of scope:** Job queue, settings, UI, production deployment, or human edits.
- **Blocked by:** EHV2-06-01, EHV2-06-02.
- **Priority:** High.
- **Model class:** Complex — private media egress, subprocess preparation, and provider response validation form one bounded integration seam.

## EHV2-06-04 — Queue selected and bulk transcription jobs

- **Goal:** Transcribe one selection or all eligible voice/video notes through recoverable bounded jobs.
- **Repository:** `/home/matthijs/projects/echohoard`
- **Context / constraints:** Reuse PostgreSQL job patterns and one worker role. Bulk means a frozen query/selection manifest, not an unbounded request. Manual-authoritative transcripts are skipped unless the owner explicitly requests a new non-active version.
- **Work to do:** Add plan/create/claim/run/retry/cancel/status services; snapshot selected model and media digests; bound concurrency/rate/size; emit sanitized progress counters.
- **Acceptance criteria:** Duplicate submission is idempotent; selected and all-eligible plans are reviewable/count-bounded; restart resumes safely; manual-authoritative items are not overwritten; cancellation stops future claims and preserves completed versions.
- **Verification:** Unit state-machine tests and PostgreSQL functional tests for selection, bulk pagination, replay, concurrency, restart, cancellation, provider errors, and manual skip.
- **Out of scope:** Rendering/editing, scheduler, cost estimation beyond observed counters, or private deploy.
- **Blocked by:** EHV2-06-03, EHV2-05-03.
- **Priority:** High.
- **Model class:** Medium.

## EHV2-06-06 — Edit transcripts and preserve human authority

- **Goal:** Let the owner correct transcript text and guarantee later automated runs cannot overwrite it.
- **Repository:** `/home/matthijs/projects/echohoard`
- **Context / constraints:** Save creates an immutable manual version with editor/time/reason metadata and optimistic concurrency. Revert selects an older version but never deletes history.
- **Work to do:** Add edit/revert commands, validation/limits, version history reads, manual-authority transition, and accessible editor/history UI.
- **Acceptance criteria:** Manual save is audited/versioned and becomes active; concurrent edit conflicts do not lose text; automatic completion after edit remains a non-active version; owner can inspect/revert versions; content is absent from logs/audit metadata.
- **Verification:** Domain/unit, PostgreSQL concurrency/version tests, and browser edit/revert/late-automation flows.
- **Out of scope:** Collaborative editing, AI rewrite, translation, or physical purge implementation.
- **Blocked by:** EHV2-06-01, EHV2-06-05.
- **Priority:** High.
- **Model class:** Medium.
