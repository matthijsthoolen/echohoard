# EH-09 stories — Private read-only MCP

Owning feature: docs/tasks/EH-09.md. Only the leaf stories below are executable assignments.

## EH-09-01 — Establish MCP transport, authentication, and archive principal

- **Goal:** Start an official TypeScript MCP Streamable HTTP server whose authenticated principal maps to exactly one Archive.
- **Repository:** /home/matthijs/projects/echohoard
- **Context / constraints:** Dedicated read-only credential enters through a secret file; transport is private; handlers reuse application services and never query PostgreSQL directly.
- **Work to do:** Add MCP composition/initialize transport; implement bounded credential validation and archive-principal mapping; add invalid/missing/cross-archive functional tests.
- **Acceptance criteria:** Authenticated initialization succeeds for the configured principal; missing/invalid credentials fail without archive metadata; no mutation/file/network tool exists; credentials are absent from logs/errors.
- **Verification:** Run MCP initialize/auth functional tests against PostgreSQL and inspect logs/process configuration with sentinel credentials.
- **Out of scope:** Individual tools, public OAuth, Hermes registration, and production networking.
- **Blocked by:** EH-06-01, EH-07-01.
- **Priority:** High.
- **Model class:** Medium.

## EH-09-02 — Expose bounded conversation and message-search tools

- **Goal:** Implement search_messages, get_conversation, and list_conversations using existing application services.
- **Repository:** /home/matthijs/projects/echohoard
- **Context / constraints:** Inputs/outputs have strict count, text, context, date-range, cursor, and payload bounds; source text is untrusted evidence.
- **Work to do:** Define the three schemas/descriptions; map handlers to EH-06 services; add pagination, oversize, empty, hostile-text, and archive-isolation tests.
- **Acceptance criteria:** Each tool returns bounded provenance-bearing results; invalid/oversized inputs fail schema validation; hostile message text cannot change behavior; no direct DB access appears.
- **Verification:** Run MCP discovery/call snapshots and functional tests for every schema boundary and two archives.
- **Out of scope:** Person/media/timeline/health tools, public transport, AI summaries, and live Hermes.
- **Blocked by:** EH-06-04, EH-09-01.
- **Priority:** High.
- **Model class:** Simple.

## EH-09-03 — Expose bounded person, media, timeline, and status tools

- **Goal:** Implement find_person, find_media, get_timeline, and archive_status using archive-scoped application services.
- **Repository:** /home/matthijs/projects/echohoard
- **Context / constraints:** Media results contain metadata/attachment IDs, never arbitrary paths/URLs; status contains sanitized archive evidence, never message bodies or secrets.
- **Work to do:** Define the four schemas/descriptions; map handlers to read/health services; add missing-media, ambiguous-person, pagination, hostile-metadata, and isolation tests.
- **Acceptance criteria:** All tools are bounded and provenance-bearing; media/status results expose no path/secret/content leakage; invalid auth/archive probes reveal nothing; handlers contain no persistence queries.

- **Out of scope:** Binary media transfer, mutations, memory publication, external URL fetch, and live Hermes.
- **Blocked by:** EH-05-06, EH-08-02, EH-09-01.
- **Priority:** High.
- **Model class:** Simple.

## EH-09-04 — Enforce hostile-content envelopes, audit metadata, and tool allowlist

- **Goal:** Make all MCP output explicitly untrusted and prevent accidental capability/schema expansion.
- **Repository:** /home/matthijs/projects/echohoard
- **Context / constraints:** Audit records may contain tool/principal/timing/count/status metadata, never returned content; advertised tools are exactly seven read tools.
- **Work to do:** Add common untrusted-evidence/provenance envelopes; add content-free audit metadata; add a discovery/schema allowlist snapshot and hostile-content regression suite.
- **Acceptance criteria:** Discovery exposes exactly the approved seven names; every result marks source fields untrusted; injected instructions/URLs/paths remain inert strings; audit output contains no archive content or credential.
- **Verification:** Run schema snapshot, hostile fixture calls, audit-log sentinel scans, and a deliberate extra-tool failure probe.
- **Out of scope:** Production observability, live Hermes policy, public clients, and content moderation.
- **Blocked by:** EH-09-02, EH-09-03.
- **Priority:** High.
- **Model class:** Medium.

- **Repository:** /home/matthijs/projects/echohoard

- **Verification:** Run the full MCP functional suite and inspect docs/schema snapshots for secrets and accidental tool expansion.

- **Blocked by:** EH-09-04.

- **Model class:** Medium.
