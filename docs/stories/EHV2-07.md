Owning feature: `docs/tasks/EHV2-07.md`. These stories validate composition; defects return to the owning feature leaf rather than being silently fixed here.

## EHV2-07-01 — Prove multi-account live-to-backup convergence and import recovery

- **Goal:** Validate the full observation lifecycle across two accounts, live events, overlapping backups, deletion events, and import exclusion/re-enable.
- **Repository:** `/home/matthijs/projects/echohoard`
- **Context / constraints:** Use deterministic synthetic fixtures with sentinels and an independent expected-state oracle.
- **Work to do:** Build cross-feature integration fixture/run; exercise replay, disconnect, live-only, backup confirmation, source deletion, corrupt import exclusion, re-enable, and unified-chat grouping in several orders.
- **Acceptance criteria:** Every order yields the expected logical digest; no duplicates or lost eligible content; all provenance remains enumerable; failed/excluded runs never corrupt another account; sentinel scan is clean.
- **Verification:** Run the integration suite twice plus full database/architecture/coverage gates.
- **Out of scope:** UI privacy, media recovery, transcription, or live systems.
- **Blocked by:** EHV2-01-06, EHV2-02-02, EH-13-08.
- **Priority:** High.
- **Model class:** Medium.
