# EHV2-10 feature — Production transport and release integrity

> V2 post-review remediation tracker. Execute [`docs/stories/EHV2-10.md`](../stories/EHV2-10.md).

## Outcome

Ensure private model/MCP transports, packaged readiness, CI, and tagged releases enforce the same security and quality contracts proven in repository tests.

## Start state

LiteLLM DNS validation is separate from connection resolution, MCP has no packaged transport, Compose health can pass without a usable runtime, tags can publish without full quality gates, and production integration seams are omitted from required CI.

## End state

Private egress connects only to validated addresses, MCP is callable only through authenticated bounded production composition, readiness fails closed, and no image is published until the exact SHA passes all required integration evidence.

## Acceptance criteria

- DNS changes cannot redirect private media or credentials to a public address.
- The packaged MCP endpoint authenticates and exposes only the established read-only tools.
- Compose distinguishes liveness from readiness and includes required configuration and hardening.
- Tagged images are gated on exact-SHA quality and production integration checks.

## Verification

Transport rebinding tests, packaged MCP contract tests, Compose readiness negatives, CI workflow validation, and a no-push release dry run.

## Out of scope

Private infrastructure deployment, changing LiteLLM routing, new MCP tools, or publishing a real release.

## Blocked by

EH-10-05 and EHV2-06-03.
