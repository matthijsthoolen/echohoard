# EHV2-02 feature — Reversible unified conversations

> V2 tracking contract. Execute [`docs/stories/EHV2-02.md`](../stories/EHV2-02.md).

## Outcome

Let the owner combine account-specific source chats into one presentation chat without moving messages or losing account/import provenance.

## Start state

EH-13 provides source and unified conversation persistence with one-to-one grouping; there is no merge/unmerge command or unified UI behavior.

## End state

The owner can merge and unmerge source conversations, browse one correctly ordered timeline, and inspect the original account, source chat, and contributing imports for every message.

## Acceptance criteria

- Merge/unmerge is explicit, audited, archive-scoped, reversible, and never fuzzy-automatic.
- Every source conversation belongs to exactly one active unified group.
- Timeline/search/statistics/MCP results have documented unified-versus-source semantics.
- Identical timestamps and conflicting metadata have deterministic ordering and display.

## Verification

Domain/unit tests, PostgreSQL merge/unmerge/isolation tests, browser flows, and read/MCP regression tests.

## Out of scope

Person merge, automatic name-based merge, moving source records, or modifying WhatsApp.

## Blocked by

EH-13-08.
