# EH-08 — Expose archive health and deterministic statistics

## Goal

Make archive trustworthiness and useful basic communication statistics observable without inspecting logs or relying on AI.

## Repository

`/home/matthijs/projects/echohoard`

## Context / constraints

- Health is about archive freshness/completeness, not only process liveness.
- Statistics must be deterministic PostgreSQL queries and archive-scoped.
- Never expose message bodies, filesystem paths, or secret-bearing diagnostics on health surfaces.

## Work to do

- Implement health services for discovered/completed snapshots, latest archived message, current/last jobs, durations, counts, media availability, unsupported types, and sanitized failures.
- Add configurable freshness thresholds, including warning when the latest completed snapshot is older than 36 hours by default.
- Implement statistics for totals, media by type/state, sent/received distribution, activity over time, and most-active conversations.
- Add authenticated UI pages/cards and machine-readable private health/readiness responses.
- Ensure expensive aggregates are indexed, cached safely, or incrementally maintained based on measurements, without adding another store.

## Acceptance criteria

- The dashboard distinguishes process health, snapshot freshness, import failure, unsupported data, and media coverage.
- Counts reconcile to normalized fixtures and update after successful import only.
- Statistics stay archive-scoped and meet the accepted response target at reference scale.
- Failure details are actionable but contain no source text, arbitrary paths, or secrets.

## Verification

- Unit-test status classification, thresholds, redaction, and statistic definitions.
- PostgreSQL functional-test successful/failed/in-progress/stale imports, missing media, unsupported types, and cross-archive isolation.
- Browser-test healthy, warning, failure, empty-archive, and large-count states.
- Compare displayed counts against direct fixture assertions and recorded import manifests.

## Out of scope

Prometheus/Loki, complex social analysis, AI-generated insights, notifications, and public status pages.
