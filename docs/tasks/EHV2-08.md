# EHV2-08 feature — Production ingestion integrity

> V2 post-review remediation tracker. Execute [`docs/stories/EHV2-08.md`](../stories/EHV2-08.md); do not implement this parent as one assignment.

## Outcome

Make backup and live ingestion complete, bounded, retryable, and safe under stale workers, malformed events, pairing expiry, and backup/live overlap.

## Start state

The production worker can complete after decryption without import, live intake is not composed at the deployed route, lease ownership is not fenced, poison receipts can starve the queue, edit revisions diverge across adapters, and QR expiry is only local.

## End state

Production backup jobs import before completion, live events reach durable normalization through the deployed route, stale workers cannot mutate replacement work, invalid receipts terminate safely without starvation, edits converge, and expired QR attempts are invalid upstream.

## Acceptance criteria

- Backup completion means adaptation and transactional import completed; plaintext work is cleaned after success or classified failure.
- Every job mutation is fenced by the active lease, and poison live receipts cannot block later valid events.
- The deployed signed live-event path is bounded before buffering and reaches normalization.
- Live and backup edits converge, and expired/replaced pairing attempts cannot later connect.

## Verification

PostgreSQL two-runner and ingestion tests, adapter permutation tests, fake-sidecar expiry tests, Compose contract checks, and production worker build.

## Out of scope

Private deployment, real WhatsApp pairing, new queues/services, or changes to immutable snapshot ownership.

## Blocked by

EH-13-08 and the implemented V2 live-ingestion contracts.
