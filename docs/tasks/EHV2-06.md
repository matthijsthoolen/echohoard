# EHV2-06 feature — Owner-controlled voice and video-note transcription

> V2 tracking contract. Execute [`docs/stories/EHV2-06.md`](../stories/EHV2-06.md).

## Outcome

Let the owner transcribe selected or all eligible voice/video notes using a selected LiteLLM model, display transcripts beside originals, and protect human corrections.

## Start state

Audio/video attachments can be served but have no transcript entity, jobs, provider adapter, model setting, library filter, or editor.

## End state

Settings enumerate allowed LiteLLM transcription models. Bounded jobs transcribe selected/all eligible media, store provenance/version/status, show transcripts in chat and galleries, and create protected human revisions that automatic runs cannot overwrite.

## Acceptance criteria

- Every transcript references one attachment content hash, model, timestamps, status, and version lineage.
- Model selection comes from a bounded LiteLLM catalog and is captured per job/result.
- Raw media and credentials never enter logs, Plane, Git, argv, or durable temporary files outside approved work paths.
- Human edits are marked, versioned, restorable, and never overwritten by retry/retranscription unless the owner explicitly creates a new branch/version.

## Verification

Provider contract tests, fake LiteLLM tests, job/retry functional tests, browser/library tests, manual-authority tests, and private selected-media acceptance.

## Out of scope

Speaker diarization, summaries, translation, OCR, image understanding, or autonomous model selection.
