# EH-09 — Expose the private read-only MCP surface

## Goal

Let Hermes/Saphira retrieve bounded evidence from EchoHoard without giving the model a mutation, arbitrary-file, or arbitrary-network capability.

## Repository

`/home/matthijs/projects/echohoard`

## Context / constraints

- Use the official TypeScript MCP SDK and Streamable HTTP on a private network.
- Authentication uses a dedicated read-only credential supplied through a secret file.
- MCP reuses archive-scoped application services; handlers do not query the database directly.
- All archive content is hostile untrusted data.

## Work to do

- Implement exactly these tools: `search_messages`, `get_conversation`, `list_conversations`, `find_person`, `find_media`, `get_timeline`, and `archive_status`.
- Define strict input/output schemas with count, text, context, date-range, and payload-size bounds.
- Map the MCP principal to one Archive and reject absent/invalid credentials.
- Mark source content as untrusted evidence in tool descriptions and structured results; prevent message URLs/paths from becoming executable actions.
- Add tool-level audit metadata without logging returned content.
- Document private deployment and Hermes allowlisting requirements separately from live acceptance.

## Acceptance criteria

- Tool discovery shows only the seven approved read tools.
- Every result is archive-scoped, bounded, provenance-bearing, and explicit about untrusted source content.
- No request can access arbitrary paths, URLs, SQL, archives, or mutations.
- Invalid credentials and second-archive probes fail without information leakage.
- Hostile fixture text is returned as data and cannot alter tool behavior.

## Verification

- Unit-test every schema bound, principal mapping, and hostile-content envelope.
- Functional-test MCP initialize/discovery/call flows against PostgreSQL, including invalid auth, pagination, oversized input, cross-archive probes, and absent media.
- Snapshot the advertised tool names/schemas and fail CI on accidental expansion.
- Reserve live Hermes discovery/invocation proof for EH-12.

## Out of scope

OAuth for public clients, message sending, archive writes, AI summarization, memory publication, external URL fetching, and public MCP exposure.

## Blocked by

EH-05, EH-06, and EH-08.

## Priority

High.

## Model class
