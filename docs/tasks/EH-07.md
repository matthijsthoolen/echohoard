# EH-07 — Deliver authenticated responsive archive viewer

## Goal

Give the owner a safe, familiar WhatsApp-style interface for browsing, searching, and playing archived content on desktop and mobile-width screens.

## Repository

`/home/matthijs/projects/echohoard`

## Context / constraints

- Authentik OIDC is the V1 authentication boundary.
- V1 has one admitted user, mapped to one owned Archive; internal services still enforce archive scope.
- Use ordinary Next.js route handlers/components and application services. Do not use source HTML or direct Prisma calls.

## Work to do

- Implement OIDC login/logout/session validation and map the configured subject to an EchoHoard User/Archive.
- Build responsive conversation list/detail layout, bounded timeline loading, message virtualization, replies/reactions/edits, safe rich-type placeholders, and media playback/download.
- Build global search and filter UI backed by EH-06, including navigation from a result to its context.
- Add accessible loading, empty, missing-media, unsupported-type, and error states.
- Ensure authorization is applied at route and application-service boundaries.

## Acceptance criteria

- Anonymous, invalid-session, wrong-subject, and cross-archive requests are denied.
- An authenticated owner can browse very large chats without downloading or retaining the whole conversation in the browser.
- Search/filter results navigate to stable message context.
- Required common types render safely; missing and unsupported content is explicit.
- Desktop and mobile-width critical paths are keyboard accessible and pass the selected automated accessibility checks.

## Verification

- Unit-test session/archive mapping and presentation policies.
- Functional-test OIDC callback/session logic with a fake provider and two archives.
- Browser-test login, conversation browsing, bidirectional pagination, search/filter, result context, media playback/download, hostile text, active-content blocking, responsive layout, and logout.
- Run performance/memory profiling on a synthetic 150,000-message conversation.

## Out of scope

Multi-user administration/sharing, archive mutation, custom mobile app, export, and final brand artwork.

## Blocked by

EH-05 and EH-06.
